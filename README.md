# Project and Task Management System

A console-based Python application for managing projects, employees, teams, and tasks. It supports project creation, team allocation, task assignment, priority and deadline tracking, status updates, progress calculation, and overdue task identification.

## Project files

- `main.py` — application code
- `data/projects.txt` — saved project details
- `data/employees.txt` — saved employee details
- `data/tasks.txt` — saved task details

The data files use JSON text and are updated automatically by the program.

## Run

Install Python 3.10 or later, then run:

```bash
python main.py
```

Use the numbered menu to manage records. Choose `0` to save and exit.
